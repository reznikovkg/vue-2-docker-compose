# Прототип игры "Prehistoric Fun Park Builder"

**Механика игры:**

- Представлено игровое поле в форме ромба размером 20х20 клеток (размерность можно задавать через пропсы).
- На поле можно строить объекты.
- Существует несколько вариантов объектов, такие как здания и дороги. Объекты могут быть разной площади. Визуально объекты представлены в виде 2D текстуры, прикрепляемой к занимаемой области.
- После выбора объекта, который хотим построить, показывается его предварительное расположение на игровом поле - возможно его построить или нет.
- При наличии на игровом поле дорог, ведущих от входа на поле, спавнятся человечки, которые в рандомном порядке равномерно передвигаются по этим дорогам.
- При наличии здания, ко входу которого ведёт дорога, человечек получает возможность войти в это здание, а затем, спустя случайный промежуток времени, выйти из него.
- Над каждым зданием изображён счётчик текущего количества человечков в этом здании.
- Есть возможность удаления объекта с поля.
