# Vampire Survivors Prototype

## Описание

Этот проект представляет собой прототип игры Vampire Survivors. Игрок управляет персонажем, который находится в центре экрана и может перемещаться с помощью клавиш WASD. Персонаж автоматически стреляет в направлении курсора, а противники надвигаются со всех сторон.
